# Цели на семестр

1. Освоить Docker: создать Dockerfile для учебного приложения и docker-compose.yml для запуска приложения с базой данных; проверить запуск из чистого окружения.
2. Настроить CI/CD в GitHub Actions: автоматически запускать тесты и собирать Docker-образ при push и pull request; продемонстрировать успешный и неуспешный запуск проверок.
3. Освоить Linux и Bash: написать скрипт резервного копирования с журналированием и обработкой ошибок, настроить его запуск по расписанию и проверить восстановление файлов из копии.
